# NFC 名片与视觉内容

## 静态名片首屏

- **Given** 访客通过 NFC、二维码或链接打开首页
- **When** JavaScript 尚未加载、加载失败或被禁用
- **Then** 姓名、个人简介、社交与联系入口、保存通讯录按钮仍直接可读可用，只有实时留言和分享增强不可用

## 保存到通讯录

- **Given** 访客需要保存名片信息
- **When** 点击“保存到通讯录”
- **Then** 浏览器打开 UTF-8 vCard 文件，并显示操作反馈

## 分享名片

- **Given** 访客点击“分享名片”
- **When** 浏览器支持系统分享
- **Then** 打开系统分享面板；不支持系统分享时改为复制当前名片链接，并显示对应结果

## 社交平台预览

- **Given** 支持 Open Graph 或 Twitter Card 的服务抓取名片链接
- **When** 服务读取页面元数据
- **Then** 获得当前语言的标题、简介、规范地址和 1200×630 个人名片大图

## 首页专用图片

- **Given** 访客打开首页
- **When** 首页功能卡片渲染完成
- **Then** 五张卡片分别显示“关于我、动漫、游戏、旅行、GitHub”的专用水墨风图片，而不是复用地区图或抽象线条

## 城市专用图片

- **Given** 访客打开旅行页或任一普通城市详情页
- **When** 城市视觉卡片渲染完成
- **Then** 页面优先显示与城市或相近地标组匹配的具象水墨风图片

## 日本十五日海报旅记

- **Given** 访客打开 2026 年夏季日本旅记
- **When** 专题页展示 2026 年 6 月 30 日至 7 月 14 日的行程
- **Then** 页面按日期顺序显示四个章节和十五张 4:5 旅行海报，每张都有对应的地点、日期与旅行摘要

## 日本旅记三语版本

- **Given** 访客使用中文、日文或英文版本访问日本旅记
- **When** 页面在对应语言路径下打开
- **Then** 专题标题、章节、地点、海报标签、摘要和图片替代文本都使用当前语言，不依赖客户端脚本补全正文

## 海报加载与大图

- **Given** 访客在移动网络或较小屏幕上打开日本旅记
- **When** 页面首次加载并继续向下浏览
- **Then** 首幅海报优先出现，图廊海报按需延迟加载；点击任一海报可打开完整的高清版本

## 海报文字的语义回退

- **Given** 访客使用辅助技术、图片未成功加载，或搜索服务只读取页面文本
- **When** 海报画面内的短标签无法被直接读取
- **Then** 同一幅海报仍有当前语言的图片替代文本、标签、地点、日期和摘要，画面内文字不是唯一语义来源

## 图片复用上限

- **Given** 多个相近城市共用同一张地标组图片
- **When** 图片资源检查运行
- **Then** 单张城市图片最多覆盖三个城市，避免大范围重复

## 首页多语言语录

- **Given** 访客在首页切换中文、日文或英文
- **When** 语言状态更新
- **Then** 首页副标题下方显示对应语言的生活语录

## 弱网与离线回退

- **Given** 访客曾成功打开过站点并已缓存核心资源
- **When** 后续访问遇到断网或静态资源请求暂时失败
- **Then** 页面导航优先回退到已缓存页面，头像、样式、脚本、分享图和通讯录等核心资源可从缓存读取；若从未缓存则显示明确的离线提示

## 发布后可见性

- **Given** 新版本已经由生产环境部署
- **When** 访客访问 `https://about.shuangyue.space/`
- **Then** 页面引用最新资源版本，并且头像、首页图片、城市图片、分享图和通讯录 URL 返回可用文件
