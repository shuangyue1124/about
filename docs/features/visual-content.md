# 视觉内容

## 首页专用图片

- **Given** 访客打开首页
- **When** 首页功能卡片渲染完成
- **Then** 五张卡片分别显示“关于我、动漫、游戏、旅行、GitHub”的专用水墨风图片，而不是复用地区图或抽象线条

## 城市专用图片

- **Given** 访客打开旅行页或任一城市详情页
- **When** 城市视觉卡片渲染完成
- **Then** 页面优先显示与城市或相近地标组匹配的具象水墨风图片

## 图片复用上限

- **Given** 多个相近城市共用同一张地标组图片
- **When** 图片资源检查运行
- **Then** 单张城市图片最多覆盖三个城市，避免大范围重复

## 首页多语言语录

- **Given** 访客在首页切换中文、日文或英文
- **When** 语言状态更新
- **Then** 首页副标题下方显示对应语言的生活语录

## 发布后可见性

- **Given** 新图片已经提交并部署
- **When** 访客访问 `https://about.shuangyue.space/`
- **Then** 页面引用最新资源版本，并且首页图片和城市图片 URL 返回可显示的图片文件
